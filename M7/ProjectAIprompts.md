# AI Assistance and Prompt Documentation
## SwaVe Hair Couture Lounge

### Prompt 1: Original Program Modification

**Purpose:** Transform the original house text adventure into a salon-themed program.

**Prompt used:**

"Help me change my existing house text adventure program into a barbershop/salon named SwaVe Hair Couture Lounge with seven rooms and make the Fire Exit end the game."

**Result:** The original program was modified to include seven salon rooms, room descriptions, directional connections, and a game-ending condition.

### Prompt 2: Project Planning and Requirements

**Purpose:** Develop requirements for expanding the existing program into an interactive salon simulation.

**Prompt:**

"Help me develop a requirements document for expanding my existing SwaVe Hair Couture Lounge C++ text adventure into an interactive salon management simulation. Incorporate customer registration, service selection, stylist selection, appointment management, salon navigation, loyalty points, and checkout."

### Prompt 3: Structure-Based Program Design

**Purpose:** Plan the use of C++ structures in the upgraded application.

**Prompt:**

"Help me design a C++ program using structures, structure variables, dot notation, arrays of structures, passing structures to functions, and nested structures. Apply these concepts to customer, service, stylist, appointment, and room information in my SwaVe Hair Couture Lounge program."

### Prompt 4: Program Development

**Purpose:** Expand the original program while maintaining its existing functionality.

**Prompt:**

"Help me incrementally expand my existing SwaVe Hair Couture Lounge C++ program. Preserve the original seven-room navigation system and incorporate the proposed salon management features using structures and user-defined functions. Explain the code and help me test each feature."

**AI Assistance Disclosure:**

ChatGPT (OpenAI) was used as a development and learning resource to assist with project planning, requirements documentation, preliminary software design, and C++ programming guidance. The student will review, understand, test, and evaluate all proposed code and modifications.
