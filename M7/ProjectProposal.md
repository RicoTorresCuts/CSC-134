# CSC 134 – Final Project Proposal
## SwaVe Hair Couture Lounge: Interactive Salon Management Simulation

### Project Description

For my CSC 134 final project, I propose expanding my existing C++ text adventure program, SwaVe Hair Couture Lounge, into an interactive salon management and customer experience simulation.

The original program allows users to explore seven different salon rooms using directional commands. For the final project, I plan to preserve the existing room navigation system while incorporating additional functionality that simulates a customer's experience at a professional salon.

The upgraded program will allow users to register customers, select salon services, choose stylists, navigate salon departments, and complete a simulated checkout process.

### Project Objectives

The primary objective is to demonstrate my understanding of C++ structures and how they can be used to organize related information within a program.

The project will demonstrate how structures can improve program organization, reduce the need for separate parallel arrays, and allow related information to be passed between functions.

### Planned Features and Enhancements

1. **Customer Registration:** Create customer records containing customer names, identification numbers, and loyalty points.

2. **Salon Service Menu:** Display available services, including haircuts, coloring, natural hair care, shampoo treatments, and styling, with corresponding prices and estimated durations.

3. **Stylist Selection:** Allow customers to select a stylist based on their specialty.

4. **Salon Navigation:** Retain the original seven-room text adventure and improve its room management using structures.

5. **Appointment Management:** Organize customer, service, and stylist information into an appointment record using nested structures.

6. **Checkout System:** Calculate service costs, update customer loyalty points, and generate a final receipt.

### C++ Programming Concepts

The project will incorporate the following programming concepts:

- Declaring and defining structures.
- Creating structure variables.
- Accessing structure members using dot notation.
- Arrays of structures.
- Passing structures to functions.
- Nested structures.
- Functions and modular programming.
- Loops and conditional statements.
- Arrays and two-dimensional arrays.
- Mathematical calculations and input validation.

### Expected Outcome

The expected outcome is a functional, text-based salon simulation that demonstrates how C++ structures can organize customer, service, stylist, appointment, and room information.

By expanding an existing program, this project will demonstrate my ability to apply newly learned programming concepts to an existing application while improving its functionality, organization, and overall user experience.
